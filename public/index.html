Session Management

Open these pages on http://localhost:3000 (not as a file).

Register Login Logged-in page

Flow

  1. Register page → POST /api/auth/register
  2. Login page → POST /api/auth/login
  3. If already logged in elsewhere → 409, use Force login
  4. After login popup → go to logged-in page
  5. Logged-in page connects socket and waits for force_logout
